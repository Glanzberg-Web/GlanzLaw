# Glanzberg Law Firm, PLLC — Official Website

**Website:** https://glanzlaw.com/

This repository contains the static HTML, CSS, JavaScript, and images for the Glanzberg Law Firm, PLLC website, published through GitHub Pages. The `CNAME` file identifies the custom domain.

## Pages

- `index.html` — public homepage and attorney profile
- `practice-areas.html` — practice areas
- `mediation.html` — mediation services and inquiries
- `representative-matters.html` — selected matters and case references
- `contact.html` — telephone, email, and mailing information
- `privacy.html` — website privacy notice
- `404.html` — page-not-found message

Historical addresses `jack.html` and `jack-glanzberg.html` remain accessible for old links and identify the root homepage as their canonical URL.

## Updating the site

Changes to the GitHub Pages publishing branch are deployed automatically. Shared styles are in `assets/css/site.css`; responsive navigation is in `assets/js/site.js`. Jack’s approved portrait is in `assets/img/jack-glanzberg.webp`.

The online contact form remains **inactive**. Visitors can call or email the firm using the Contact page. Before adding a form, analytics, or other new data-processing services, review the privacy notice and related settings.

The firm should continue reviewing professional statements, court information, contact details, and privacy terms as necessary.
